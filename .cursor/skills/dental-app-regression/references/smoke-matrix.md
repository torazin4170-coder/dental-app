# Smoke マトリクス — 訪問歯科カルテ

push 前・大きな変更後に使う。**「問題なし」だけの報告は禁止**。各項目を ✅ / ❌ / ⏭未確認 のいずれかで報告する。

---

## A. 共通 — テキスト強調（`rptEm*` / 強調バー / マーカー変更時は全行必須）

| ID | 画面 | 操作 | 期待結果 |
|----|------|------|----------|
| A1 | FAX日報 | プレビュー内容欄で選択 → 赤字・黄・赤枠・黒枠・解除 | 見た目＋再オープン後も残る |
| A2 | SVリスト | 同上 | 同上 |
| A3 | 情報共有シート | **左**内容欄で4強調＋解除 | **中央プレビュー**に反映 |
| A4 | 情報共有シート | **中央プレビュー**内容欄で4強調＋解除 | **左**に反映 |
| A5 | 情報共有シート | **左メモ欄**で赤字・枠 | プレビュー下部メモに反映 |
| A6 | 個別報告書 | 治療内容欄で4強調＋解除 | プレビューで見える |
| A7 | 診療記録 | メモ欄で4強調＋解除 | 編集画面で見える |
| A8 | 任意 | 改行をまたぐ選択で赤枠 | 可能な範囲で全体に枠／不可ならトースト |

---

## B. 情報共有シート専用（`iss*` / shareSheetModal 変更時）

| ID | 操作 | 期待結果 |
|----|------|----------|
| B1 | 左ペインをスクロールして内容欄を編集 | 強調バー（sticky）が見える |
| B2 | 区分・担当者変更 | プレビューが壊れず同期 |
| B3 | 写真追加 → プレビューで移動 | テキスト強調が消えない |
| B4 | 印刷プレビュー | 強調・改行が PDF に残る |

---

## C. データ・同期（GAS / gasCall / 保存変更時）

| ID | 操作 | 期待結果 |
|----|------|----------|
| C1 | Ctrl+Shift+R 起動 | 施設・患者が読める（2分以内目安） |
| C2 | 診療記録保存1回 | 二重保存なし・成功トースト |
| C3 | 保存後再表示 | 入力内容一致 |
| C4 | 写真付き患者 | 画像が表示（壊れアイコンでない） |

---

## D. 帳票出力（整形・印刷変更時）

| ID | 操作 | 期待結果 |
|----|------|----------|
| D1 | 施設月次プレビュー | 初診が二重にならない |
| D2 | **FAX / SV / ISS / 施設月次** 印刷 | プレビューと印刷で改行・空行・強調（赤字・枠）が一致 |

## E. 印刷一致 — リッチプレビュー4帳票（`rptEm*` / `*Print*` / 帳票変更時は **全行必須**）

| ID | 帳票 | 確認 |
|----|------|------|
| E1 | FAX日報 | 治療欄に空行＋赤枠 → 印刷でも同じ |
| E2 | SVリスト | メモ欄に改行＋黒枠 → 印刷でも同じ |
| E3 | 情報共有シート | メモ欄に空行＋黒枠 → 印刷でも同じ |
| E4 | 施設月次報告書 | 治療内容に改行＋強調 → 印刷でも同じ |

自動: `node scripts/check-regression-guards.mjs`（`PRINT_WYSIWYG_RULES`）

## 変更種別 → 最低限実行する行

| 触ったコード | 必須行 |
|-------------|--------|
| `rptEm*` / `fax-em-*` / 強調バー | **A1–A8** |
| `iss*` / shareSheetModal | **A3–A5, B1–B4** |
| `gasCall*` / Main.gs 同期 | **C1–C4** |
| 帳票テキスト整形 | **D1–D2** + 該当帳票の A 行 |
