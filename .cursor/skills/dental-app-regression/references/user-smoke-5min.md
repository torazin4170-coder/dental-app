# ユーザー向け 5分スモーク（大きな変更後）

本番 URL: https://dental-app-liart-five.vercel.app  
**Ctrl+Shift+R** で再読み込してから実施。

```
□ 1. 起動 — 施設・患者が選べる（真っ白のまま固まらない）
□ 2. 診療記録 — 1件保存 →「保存しました」→ 開き直して内容が残る
□ 3. 写真 — 患者1人で画像が1枚以上見える（壊れアイコンでない）
□ 4. 情報共有シート — 左の内容欄で赤字 → 右プレビューにも赤字
□ 5. 情報共有シート — 右プレビューで黒枠 → 左にも反映（または再オープンで残る）
```

**5項目中1つでも失敗 → その変更は本番投入を止め、チャットで報告。**
